## Default Permission

Allows every command this plugin exposes.

#### This default permission set includes the following:

- `allow-ping`
- `allow-probe-source`
- `allow-start-convert`
- `allow-start-merge`
- `allow-cancel-job`
- `allow-estimate-sizes`
- `allow-set-preview-files`
- `allow-engine-status`
- `allow-engine-set-path`
- `allow-engine-install`
- `allow-engine-cancel`
- `allow-engine-remove`
- `allow-engine-prompt`
- `allow-engine-set-prompted`
