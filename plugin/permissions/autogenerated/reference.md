## Default Permission

Allows every command this plugin exposes.

#### This default permission set includes the following:

- `allow-ping`
- `allow-probe-source`
- `allow-start-convert`
- `allow-cancel-job`
- `allow-estimate-sizes`
- `allow-set-preview-files`
